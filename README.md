### Prerequisites

Install python. I recommend to use the [Python install manager](https://www.python.org/downloads/) to install and use any version of python easily.

### Installation

_Once you have installed python you can run python files using ```py``` or ```python3```._

1. Clone the repo

   ```sh
   git clone https://github.com/JaydenProgram/Pythle.git
    ```

2. Change git remote url to avoid accidental pushes to base project

   ```sh
   git remote set-url origin github_username/repo_name
   git remote -v # confirm the changes
   ```
<!-- USAGE EXAMPLES -->
## Usage

1. Run without any arguments to randomize word

   ```sh
   py ./pythle
   ```

2. Run with arguments with custom word

    ```sh
   py ./pythle pythle
   ```

_For mor examples, please refer to [.vscode](https://github.com/JaydenProgram/Pythle/tree/main/.vscode) for more ways of running the app._
